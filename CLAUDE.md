# CLAUDE.md

Notes for AI assistants working on this repo. Humans: see [README.md](README.md).

## Working with this repo

- Commit messages follow Conventional Commits — see README "Contributing" for the spec and examples.
- **Do not co-author commits with AI assistants.** Don't add `Co-Authored-By: Claude ...` trailers, don't sign as the AI in any other way.
- The hardware refresh-cadence rules in README.md are panel-protection critical. Read them before changing display code — back-to-back full refreshes have already destroyed one panel on this project.
- This file is not the place for project documentation. Volatile or human-relevant content (layout, API surface, build commands, datasheet references) belongs in README.md, not here.
